# 日本市場向け製品マーケティングコンテキスト

## このスキルの目的

**このファイルは `client-template.md` の設計ガイドです。**

実際の制作では `clients/クライアント名.md`（client-templateをコピーして作成）を使う。
このファイルは「クライアントファイルに何を・なぜ・どう書くか」を説明する参照資料として機能する。

```
jp-product-marketing.md   ← 設計の考え方・各項目の意図を説明（このファイル）
client-template.md        ← 実際に使う雛形
clients/クライアント名.md  ← クライアントごとに作る実ファイル
```

ここで整理した情報（製品・ターゲット・言葉・競合など）を他のスキル（`jp-ad-creative`・`jp-copywriting`など）が参照することで、毎回ゼロから説明する手間がなくなる。

**保存先：** 実ファイルは `clients/クライアント名.md` として保存する。

---

## 使い方

### 既存ファイルがある場合
- 内容を読み込み、どのセクションを更新するかを確認する
- 変更が必要な部分のみ更新する

### 新規作成の場合

**オプションA（推奨）：既存資料からの自動生成**
- 会社サイト・商品ページ・パンフレット・過去の広告などを読み込んで初稿を生成
- 生成した内容をユーザーが確認・修正・補足する

**オプションB：質問形式で作成**
- 以下のセクションに従って一問一答で情報を集める

## 収集するセクション

### 1. 製品・サービス概要

- **一行説明：** 何者か（10〜20文字）
- **詳細説明：** 何をするか（3〜5文）
- **カテゴリ：** 競合と同じ棚に並べた場合、何と呼ばれるか
- **種別：** SaaS / EC / アプリ / 実店舗 / サービス業 / 製造業 など
- **価格帯：** 主要プランと価格

---

### 2. ターゲット

**BtoCの場合：**
- 年齢・性別・居住エリア・職業・家族構成
- 購買のトリガー（何があったら買うか）
- よく使うSNS・情報収集の方法
- 消費行動の特徴（衝動買い傾向 / 慎重に比較 / 口コミ重視 など）

**BtoBの場合：**
- ターゲット企業（業種・規模・エリア）
- 購買に関わる人物（担当者・意思決定者・承認者）
- 稟議・決裁のプロセス（承認者は何人か・決裁期間は）
- 意思決定の主な阻害要因（コスト・セキュリティ・導入工数・前例のなさ）

---

### 3. ペルソナ（具体的な人物像）

最も重要なターゲット人物を1〜2名、できるだけ具体的に記述する。

```
【ペルソナ名（仮名）】田中さとこ、37歳
職業：中小企業の経理担当（従業員50名）
生活：埼玉在住、子ども2人、時短勤務中
悩み：月末の帳票作業で毎月残業が発生する。ExcelとシステムをOHOHで転記する二度手間がストレス。
情報収集：Twitterで仕事術アカウントをフォロー。職場の同僚からの口コミも重視。
心理：「失敗したくない」「上司への説明が通るか」「本当に使いこなせるか」が不安
```

---

### 4. 顧客の悩み・ペインポイント

**現状の課題：** 商品なしで何が起きているか
**現在の解決策の不満：** 今使っているものの何が嫌か
**コスト：** 放置するとどんな損害があるか（時間・お金・精神的負担）
**感情的な痛み：** どんな気持ちになっているか（焦り・疲れ・恥・不安）

---

### 5. 競合と差別化

**直接競合：** 同じ問題を同じ方法で解決する競合（社名・特徴）
**間接競合：** 別の方法で同じ問題を解決するもの（Excel・人力・他業種のツール）
**代替行動：** 何もしないという選択肢

**各競合に対して：**
- どこが顧客に刺さっているか
- どこが弱いか（顧客が感じる不満）
- 自社がその弱点をカバーできるか

**自社の差別化ポイント：**
- 競合にはない何か（機能・価格・サポート・哲学）
- 顧客が選ぶ理由（顧客の言葉で）

---

### 6. 購買の障壁（スイッチングダイナミクス）

**プッシュ要因（現状から離れる理由）：**
今使っているやり方・サービスへの不満

**プル要因（自社への魅力）：**
自社のどこが引き付けているか

**習慣・惰性（乗り換えを妨げるもの）：**
今のやり方を変えたくない理由・面倒さ

**不安（乗り換えへの恐れ）：**
自社に切り替えることへの懸念

---

### 7. 顧客の言葉

**問題の表現（顧客がどう言っているか）：**
- 「〇〇が大変で…」「〇〇がうまくいかなくて…」などの実際の言葉

**自社の表現（顧客がどう言っているか）：**
- レビュー・口コミ・問い合わせ・SNS投稿からの実際の言葉

**使うべき言葉：** （顧客が使う表現）
**使わない言葉：** （自社だけが使う専門用語・業界用語）

**用語集：**
| 自社の用語 | 顧客が使う言葉 |
|-----------|--------------|
| | |

---

### 8. ブランドの声と個性

**トーン：** 親しみやすい / プロフェッショナル / 権威的 / その他
**文体：** ですます調 / だ・である調 / 混在
**温度感：** 共感重視 / データ重視 / ミックス
**個性（3〜5語で）：** 例：「誠実・丁寧・真剣・分かりやすい・親身」

**やってはいけないこと：**
- 使ってはいけない表現・言葉
- 避けるべきトーン

---

### 9. 実績・証拠

**数字：** 導入数・継続率・改善効果など
**顧客：** 特筆すべき顧客・業界
**受賞・掲載：** メディア・アワード（媒体名・年度）
**主な価値テーマと根拠：**
| テーマ | 根拠 |
|--------|------|
| | |

---

### 10. 目標とKPI

**ビジネス目標：** （例：新規リード月100件、購入率3%向上）
**主要な転換アクション：** 何をゴールにするか（購入・問い合わせ・資料請求）
**現在の数字：** CVR・CPAなど（分かる範囲で）

## 注意点

- 情報が少ない状態でも「分かる範囲で作る → 実際に運用しながら補う」が正しい順序
- 顧客の言葉は「自社が思う言葉」ではなく「顧客が実際に使う言葉」を収集する
- 競合分析は「悪口」ではなく「客観的な比較」として書く
- 定期的に更新する（最低3ヶ月に1回）
