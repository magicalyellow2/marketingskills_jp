# 日本語スロップ除去（Stop Slop）

## 概要

AIが生成した日本語文章には、人間が書いた文章と区別できる「AI臭さ」のパターンがある。このスキルは、そのパターンを見つけ出し、自然な日本語に書き直すためのガイドだ。

広告コピー・LPの本文・SNS投稿・メールなど、すべての文章に適用できる。

---

## コアルール

### 1. 前置きを切る

AIは本題に入る前に「クッション言葉」を置く癖がある。それを全部削る。

```
❌ 「もちろん、ご質問にお答えします」（クッション）
❌ 「確かに、〇〇は重要な課題です」（認め前置き）
❌ 「素晴らしいポイントですね」（褒め前置き）
❌ 「このたびは大変重要なテーマについて」（格調前置き）

✅ 本題から始める
```

### 2. 副詞を殺す

副詞はほぼ不要。あると文章が弱くなる。

```
❌ 「非常に重要です」→ ✅「重要です」または具体的な理由を書く
❌ 「とても効果的です」→ ✅「〇〇%改善しました」
❌ 「大変お手数ですが」→ ✅「お手数ですが」または削除
❌ 「少々お時間をいただき」→ ✅「お時間をいただき」

例外：「明日」「初めて」「すぐに」などの時間・状態を具体化する副詞はOK
```

### 3. 受動態を能動態にする

誰が何をするのかを明確にする。

```
❌ 「〇〇が提供されています」→ ✅「〇〇社が提供しています」または「〇〇を提供します」
❌ 「多くの方に選ばれています」→ ✅「〇万人が選びました」
❌ 「問題が解決されます」→ ✅「このツールが問題を解決します」
```

### 4. 抽象を具体にする

AIは抽象的な言葉でまとめようとする。必ず具体的な何かに置き換える。

```
❌ 「様々なビジネスシーン」→ ✅「営業・経理・人事など」
❌ 「多くの企業」→ ✅「製造業・小売業・IT企業など1,200社以上」
❌ 「効率化が実現します」→ ✅「月次の処理時間が平均8時間から45分に短縮します」
❌ 「課題を解決します」→ ✅「〇〇という課題を解決します」
```

### 5. テンプレ構造を壊す

AIは「問題・原因・解決策・まとめ」という同じ構造を繰り返す。読者は気づく。リズムを変える。

```
❌ すべての段落が「〇〇です。〇〇があります。だから〇〇が重要です」で終わる
❌ 見出しが「〇〇のメリット」「〇〇のデメリット」「まとめ」という教科書構成
❌ 毎段落が同じ長さ・同じリズム

✅ 短文と長文を混在させる
✅ 箇条書きと文章を交互に使う
✅ 時に逆説・疑問・具体的な場面描写から始める
```

### 6. 「サンドイッチ」を削る

AIは結論の前後に同じことを言う。最初か最後だけに絞る。

```
❌ 「〇〇が重要です。なぜなら〇〇だからです。したがって〇〇が重要と言えます」
✅ 「〇〇が重要な理由は〇〇だからです」

❌ 「まとめると、今回ご紹介したのは〇〇でした。〇〇が課題の方にぜひ〇〇をお試しください」
✅ 「〇〇でお困りなら、〇〇をお試しください」
```

### 7. 空虚な問いかけを削る

AIは「ですが、いかがでしょうか？」「ぜひ考えてみてください」などの空疎な問いかけで文章を締める。切る。

```
❌ 「〇〇について、あなたはどのようにお考えでしょうか？」
❌ 「この機会にぜひご検討ください」
❌ 「ご参考になれば幸いです」

✅ 次のアクションを明確に指示する
  「今すぐ無料で試してください」
  「気になる方は以下から資料を請求してください」
```

## 日本語AI文章の特定フレーズリスト

以下のフレーズが出てきたら削除・書き直しのサイン：

### 枕ことば系（削除）
- 「もちろん、」
- 「確かに、」「確かに〇〇ですが、」
- 「そうですね、」
- 「おっしゃる通り、」
- 「素晴らしいご質問です」
- 「非常に興味深い点ですね」
- 「ご指摘の通り、」

### まとめ・接続系（書き直し）
- 「以上をまとめると、」
- 「結論として、」
- 「したがって、」（多用時）
- 「このように、」（多用時）
- 「それでは、〇〇について見ていきましょう」
- 「次に、〇〇について説明します」

### 空虚な強調系（削除または具体化）
- 「非常に重要な」
- 「大変効果的な」
- 「極めて有用な」
- 「まさに〇〇のための」
- 「〇〇の新常識」
- 「ゲームチェンジャーとなる」

### 過剰な敬語系（整理・簡略化）
- 「〜させていただきます」（多用）
- 「ご利用いただけますと幸いでございます」
- 「何卒ご理解賜りますようお願い申し上げます」
- 「お力添えいただけますよう伏してお願い申し上げます」

### 意味のない形容詞系（削除）
- 「高品質な」（何に比べて？）
- 「革新的な」（根拠は？）
- 「シームレスな」（具体的には？）
- 「ホリスティックな」
- 「インクルーシブな」（文脈によらない多用）

## 書き直しのクイックチェック

文章を書いたら、以下を確認する：

- [ ] 前置きや「クッション」から始まっていないか
- [ ] 副詞（非常に・大変・とても）を削っても意味が通るか
- [ ] 受動態を能動態に変えられるか
- [ ] 「様々な」「多くの」を具体的な言葉に置き換えられるか
- [ ] 同じリズム・同じ長さの文が3文以上続いていないか
- [ ] 同じことを最初と最後に繰り返していないか
- [ ] 「ご参考になれば」「いかがでしょうか」で締めていないか
- [ ] 声に出して読んで自然か（「話し言葉で言えない文」は書き言葉でも変）

---

## スコアリング（1〜10点）

| 軸 | 問い |
|----|------|
| 直接性 | 前置きなしに本題から入っているか |
| リズム | 文の長さ・構造に変化があるか |
| 読者尊重 | 読者の知性を信頼した書き方か |
| 人間らしさ | 声に出して自然に読めるか |
| 密度 | 削れる言葉・文がないか |

35点以下：書き直し必要
40点以上：納品可能レベル
