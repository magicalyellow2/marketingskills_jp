# 日本語広告クリエイティブ

## はじめに確認すること

**クライアントファイルを先に確認：**
`clients/クライアント名.md`が存在する場合は必ず先に読み込み、製品・ターゲット・トーン・承認済み表現・法規制の適用範囲を把握してから制作に入る。

制作開始前に以下を確認する：

### 1. 媒体とフォーマット
- 出稿媒体（Google/Meta/LINE/Yahoo!/Twitter(X)/その他）
- フォーマット（検索広告・ディスプレイ・動画・SNSフィード・ストーリーズ）
- 既存の広告があるか（改善か新規か）

### 2. 商品・サービス
- 何を訴求するか（商品・機能・キャンペーン・無料体験など）
- 核心的なベネフィット（機能ではなく、得られる変化）
- 競合との違い

### 3. ターゲット
- 年齢・性別・居住エリア・職業など
- 購買意識のステージ（認知/比較/検討/購入直前）
- 日常の悩み・文脈

### 4. 法的制約の確認（必須）
- 業界（医薬品・化粧品・健康食品・金融・不動産など）
- 景表法・薬機法・金融商品取引法などの適用確認
- 使用できない表現の確認

## 日本語広告の媒体別仕様

### Google広告（レスポンシブ検索広告）

| 要素 | 制限 | 数量 |
|------|------|------|
| ヘッドライン | **全角15文字／半角30文字** | 最大15本 |
| 説明文 | **全角45文字／半角90文字** | 最大4本 |
| 表示URL パス | 半角15文字×2 | 2つ |

**日本語固有の注意：**
- 全角1文字＝半角2文字換算（Googleの内部計算）
- 句読点・括弧・記号も全角は2文字分消費
- 体感的な目安：ヘッドライン13〜15文字、説明文40〜44文字で収めると安全

**RSA（レスポンシブ検索広告）の日本語ルール：**
- ヘッドラインはどの組み合わせでも単独で意味が通ること
- 検索キーワードを含むヘッドラインを最低1本
- ベネフィット訴求ヘッドラインを最低1本
- CTA（行動喚起）ヘッドラインを最低1本
- 同じ意味の繰り返しになるヘッドラインの組み合わせを避ける

---

### Meta広告（Facebook / Instagram）

| 要素 | 推奨文字数 | 備考 |
|------|-----------|------|
| プライマリテキスト | 全角60〜80文字（最大2200文字） | 冒頭3行が命 |
| ヘッドライン | **全角17〜20文字** | 画像下に表示 |
| 説明文 | 全角15文字前後 | 一部配置では非表示 |

**日本市場固有の傾向：**
- スマートフォン縦長での表示が主流（PCより見切れやすい）
- テキスト量が多い広告は日本では比較的受け入れられやすい（丁寧さの文化）
- ただし「冒頭で止まれるか」が最重要

---

### LINE広告

| 要素 | 文字数制限 |
|------|-----------|
| タイトル | 全角25文字 |
| 説明文 | 全角75文字 |

**LINE広告の特性：**
- ユーザーの「プライベート空間」に入る広告であることを意識
- 押しつけがましいトーンは特に嫌われる
- 生活密着型・口語的なコピーが馴染みやすい
- LINEのUI・配色に馴染む視覚的設計が必要

---

### Yahoo!広告（検索広告）

| 要素 | 制限 |
|------|------|
| タイトル | 全角15文字×3本 |
| 説明文 | 全角45文字×2本 |

**Yahoo!広告の特性：**
- 40〜60代のユーザー比率がGoogleより高い
- 旅行・金融・保険・ショッピング系の強いプラットフォーム
- 丁寧語・信頼訴求が有効な傾向

---

### Twitter(X)広告

| 要素 | 制限 |
|------|------|
| ツイート本文 | 280文字（日本語は1文字＝2文字換算で実質140文字） |
| カードヘッドライン | 全角35文字 |

**Twitter(X)の特性：**
- 拡散・共感・話題性を意識したコピー
- ハッシュタグは1〜2個まで（多すぎると逆効果）
- リアルタイム性・トレンドとの連動が有効

## 日本語コピーの生成フレームワーク

### Step 1：アングル（訴求軸）の設定

1本の広告に1つのアングルを明確にしてから書く。複数の訴求を混ぜない。

| アングル | 具体例 | 向いている状況 |
|----------|--------|---------------|
| **悩み解決** | 「〇〇で困っていませんか」 | 認知・比較ステージ |
| **結果・変化** | 「〇日で〇〇が変わった」 | 比較・検討ステージ |
| **社会的証明** | 「〇万人が選んだ」「★4.8」 | 比較・購入ステージ |
| **権威・信頼** | 「医師監修」「〇〇受賞」 | 購入直前ステージ |
| **限定・緊急性** | 「本日限り」「残り〇席」 | 購入直前ステージ（真実のみ使用） |
| **比較優位** | 「従来品比〇〇%削減」 | 競合意識ステージ |
| **共感・世界観** | ターゲットの日常を描写 | 認知ステージ・ブランディング |
| **好奇心・意外性** | 「実は〇〇だった」 | 認知・エンゲージメント |

### Step 2：ヘッドライン生成

各アングルで複数バリエーションを作る。バリエーションは「単語の置き換え」ではなく「構造の変更」で差別化する。

**ヘッドラインの型（日本語）**

```
[悩み直球型]
「〇〇がうまくいかない方へ」
「〇〇に疲れていませんか」
「なぜ〇〇できないのか」

[結果提示型]
「〇日で〇〇を実現」
「〇〇が〇%改善した理由」
「〇〇せずに〇〇する方法」

[数字・実績型]
「〇万人が実感した〇〇」
「導入企業〇社突破」
「満足度〇〇%」（景表法要件を満たす場合のみ）

[問いかけ型]
「〇〇、もう諦めていませんか？」
「〇〇を選ぶ基準、正しいですか？」

[限定型]
「初回限定〇〇%OFF」
「先着〇名様のみ」（在庫・枠が実在する場合のみ）

[権威型]
「〇〇専門家が認めた」
「〇〇受賞の〇〇」
```

### Step 3：説明文・プライマリテキスト生成

**構造の基本：**
```
[冒頭] 悩みへの共感 or 結果の提示
[中間] 根拠・理由・特徴（最も重要な1〜2点に絞る）
[末尾] CTA（行動喚起）
```

**日本語CTAの選択肢：**

| 強さ | CTA例 |
|------|-------|
| 強（購入直前向け） | 「今すぐ申し込む」「購入はこちら」「無料で始める」 |
| 中（比較・検討向け） | 「詳しくはこちら」「無料資料を受け取る」「まずは見てみる」 |
| 弱（認知向け） | 「〇〇を知る」「詳細を確認する」 |

## 法的制約のチェック（必須）

### 景品表示法（景表法）

以下の表現は**根拠がなければ使用不可**：
- 「No.1」「1位」「最高」「最安」「業界初」
- → 使用する場合：調査機関名・調査対象・調査時期・調査方法を明示

**使用できない表現の例：**
- 「必ず〇〇になります」（効果の断言）
- 「〇〇するだけで痩せる」（誇大広告）
- 根拠のない比較（「他社比〇%安い」など）

### 薬機法（旧薬事法）

医薬品・医療機器・化粧品・健康食品に適用：

**化粧品：**
- 「治る」「治療」「改善」→ 使用不可（医薬品的効能の標榜）
- 「うるおいを与える」「洗浄する」→ 化粧品の効能の範囲内でOK

**健康食品・サプリメント：**
- 「〇〇が治る」「〇〇に効く」→ 使用不可
- 機能性表示食品・特保は届出内容の範囲で表示可

**よく使われる回避表現：**
- 「〇〇をサポートする」「〇〇に着目した」「〇〇を応援する」
- ただし脱法的な使い方も規制対象となってきているため注意

### 金融商品取引法

金融商品の広告：
- 元本割れリスクの明示義務
- 過去実績の強調表現に制限
- 「必ず儲かる」「リスクゼロ」→ 使用不可

## 品質評価チェックリスト

生成した広告コピーを納品前に確認：

### 文字数チェック
- [ ] 各媒体の文字数制限内に収まっているか（全角換算で確認）
- [ ] RSAは各ヘッドラインが単独で意味をなすか

### コピー品質
- [ ] ターゲットの悩みに刺さる冒頭になっているか
- [ ] ベネフィット（機能ではなく変化）が明確か
- [ ] CTAが明確で、次のアクションが分かるか
- [ ] 複数のアングルが混在して訴求がぼやけていないか

### 法的チェック
- [ ] 最上級表現に根拠があるか
- [ ] 業界特有の薬機法・景表法制約をクリアしているか
- [ ] 「必ず」「絶対」「誰でも」などの断定表現を使っていないか

### 日本語として自然か
- [ ] 口語として読んで違和感がないか（声に出して確認）
- [ ] 敬語・丁寧語のレベルがターゲットに合っているか
- [ ] カタカナ語の使用がターゲットに適切か（シニア向けは特に注意）
