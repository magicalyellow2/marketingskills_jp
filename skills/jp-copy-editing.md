# 日本語コピー編集

## 基本方針

**クライアントファイルを先に確認：**
`clients/クライアント名.md`が存在する場合は先に読み込み、ブランドボイス・ターゲット・顧客の言葉・承認済み表現・禁止表現を把握してから編集に入る。

コピー編集は「書き直し」ではなく「磨くこと」。
核心のメッセージを変えず、伝わり方を最大化する。

**7つのスウィープ（確認軸）を順番に通す。**
各スウィープで見つけた問題を修正した後、前のスウィープに戻って確認する。

---

## スウィープ1：明確さ（Clarity）

**問い：読んで瞬時に意味が取れるか？**

### チェックポイント

- 主語が不明確な文はないか
- 一文で複数のことを言いすぎていないか
- 抽象的な言葉が具体的な意味を持っているか
- 読者が知らない専門用語・社内用語がないか
- 指示語（これ・それ・あれ）の指す対象が明確か

### よくある問題と修正例

```
❌ 「本ソリューションは、多様なビジネスシーンにおいてシームレスな
    オペレーションを実現します」
✅ 「このツールは、営業・経理・人事など部署をまたいで
    すぐに使い始めることができます」

❌ 「それを活用することで、さまざまな課題が解決されます」
✅ 「このシステムを使うと、在庫管理にかかる工数を週10時間削減できます」
```

### 明確さを下げる日本語特有のパターン

- 主語の省略が多すぎる（読者が誰の話か迷う）
- 複文・重文の多用（一文が長くなりすぎる）
- 「〜させていただく」の多用（必要以上に重くなる）
- 二重否定（「〜でなくはない」「〜しないわけではない」）

## スウィープ2：トーンと一貫性

**問い：読み通して声が一貫しているか？**

### チェックポイント

- 丁寧語・普通体が混在していないか
- セクションによってカジュアル/フォーマルが変わっていないか
- ブランドの「らしさ」が全体を通して維持されているか
- 人称の揺れはないか（「あなた」「お客様」「ご利用者様」が混在）

### よくある問題

```
❌ ヘッドライン：「毎日の作業、もっとラクにしませんか」（カジュアル）
   本文：「本製品は、業務効率化に特化したソリューションです」（フォーマル）

✅ ヘッドライン：「毎日の作業、もっとラクにしませんか」（カジュアル）
   本文：「面倒な繰り返し作業を自動化して、大事な仕事に集中できます」（カジュアル統一）
```

---

## スウィープ3：So What（だから何？）

**問い：すべての主張に「読者にとっての意味」があるか？**

### テスト

各文・各主張の後に「だから何？」と問いかける。
その答えがコピーに書かれていなければ追記するか、削除する。

```
❌ 「当社は創業20年の実績があります」
   → だから何？ → 読者への意味がない

✅ 「創業20年、3,000社の課題解決で積み上げたノウハウを
    そのままあなたの会社に活かします」
   → 読者への意味（自分に適用できる実績）が明確
```

### 機能からベネフィットへの変換

| 機能（特徴） | 変換後のベネフィット |
|-------------|-------------------|
| 「AIが自動分類します」 | 「分類作業にかかる1日1時間が、ゼロになります」 |
| 「クラウド対応です」 | 「外出先でもスマートフォンから即座に確認できます」 |
| 「24時間サポート」 | 「深夜のトラブルでも、すぐに解決できます」 |

## スウィープ4：証拠（Prove It）

**問い：主張に裏付けはあるか？**

### 根拠なしに使えない表現

- 「業界最高水準」「No.1」「最安値」「最先端」
- 「多くのお客様に」「圧倒的な支持」
- 「効果が実証されています」

### 証拠の強さの順位

1. **第三者機関のデータ**（調査会社・研究機関）
2. **実名・顔写真つきの顧客証言**
3. **具体的な数字**（導入社数・改善率・継続率）
4. **メディア掲載・受賞歴**（媒体名・年度を明記）
5. **匿名の口コミ・評価**（プラットフォーム名を添える）

### 景表法に沿った表記方法

```
❌ 「顧客満足度No.1」（根拠不明）
✅ 「顧客満足度No.1（〇〇調査機関調べ、2024年3月、
    〇〇カテゴリ、対象：導入企業〇社）」

❌ 「〇〇%が満足と回答」（条件不明）
✅ 「〇〇%が満足と回答（自社調べ、2024年2月、
    n=〇〇〇、利用開始3ヶ月以上のユーザー対象）」
```

## スウィープ5：具体性（Specificity）

**問い：曖昧な表現を具体的な言葉に置き換えられるか？**

### 曖昧ワードリストと置き換え案

| 曖昧な表現 | 具体的な表現 |
|-----------|------------|
| 「多くの」 | 「2,400社以上の」「調査対象の78%が」 |
| 「早い」 | 「平均3営業日以内に」「最短即日で」 |
| 「安い」 | 「月額〇〇円から」「他社比平均〇〇%コスト削減」 |
| 「簡単に」 | 「3ステップで」「5分で完了する」 |
| 「効果的な」 | 「〇〇%改善した」「〇〇件の課題を解決した」 |
| 「最適な」 | 「〇〇という条件に合う」 |
| 「充実した」 | 「〇〇種類の機能が含まれる」 |

### 数字の使い方

- 「約〇〇」より「〇〇」（根拠があるなら端数も有効）
- 大きい数字は「万」単位に換算（「10,000社」→「1万社」）
- 割合は母数と対象期間を添える

## スウィープ6：感情的共鳴（Emotional Resonance）

**問い：読者の感情に触れているか？**

### 日本市場で有効な感情軸

| 感情 | 活用するコピーの方向 |
|------|-------------------|
| **不安の除去** | 「〇〇でも大丈夫」「解約はいつでも」「返金保証あり」 |
| **承認・安心** | 「〇〇万人が利用中」「専門家も推薦」「〇〇受賞」 |
| **共感** | 「〇〇に悩んでいませんか」「私たちも同じでした」 |
| **誇り・自己肯定** | 「〇〇を選ぶ方は〇〇な人です」 |
| **好奇心** | 「なぜ〇〇なのか、理由は〇つあります」 |
| **希望** | 「〇週間後には〇〇できるようになります」 |

### 感情を高める技術（日本語）

**before/afterの描写：**
```
「毎月末の3日間、深夜まで残業していた経理担当の〇〇さんが、
 このツールを導入してから残業がゼロになりました」
```

**読者の心の声を代弁する：**
```
「『どうせ自分には難しいだろう』と思っているかもしれません。
 でも、実際に始めた方の〇〇%が『思ったより簡単だった』
 とおっしゃっています」
```

## スウィープ7：リスクゼロ（Zero Risk）

**問い：購入・申し込みの障壁を最大限取り除いているか？**

### 日本市場で特に有効なリスク除去の言葉

| リスク | 除去の表現 |
|--------|-----------|
| 費用リスク | 「30日間全額返金保証」「成果が出なければ全額返金」 |
| 契約リスク | 「いつでも解約できます」「違約金なし」「年縛りなし」 |
| 学習コスト | 「設定はスタッフが代行します」「使い方は30分で習得できます」 |
| 個人情報 | 「クレジットカード登録不要」「メールアドレスのみで開始」 |
| 意思決定リスク | 「まず無料で体験してから」「お試し期間中は全機能が使えます」 |

### CTAの直前に置くリスク除去の文言

```
✅「今すぐ無料で始める（クレジットカード不要・いつでも解約可）」
✅「まず30日間、無料でお試しください」
✅「相談だけでも大丈夫です。営業電話はしません」
```

## 日本語特有の削除リスト（カット・置き換えの対象）

### 不要な謙遜・過剰敬語
```
❌ 「〜させていただきます」を多用（2回以上連続）
   → 1回に絞る、または「します」に置き換える

❌ 「ご利用いただけますと幸いでございます」
✅ 「ご利用ください」または「ぜひお試しください」
```

### 意味のない前置き
```
❌ 「皆様のご要望にお応えするため、このたび〜」
✅ （前置きを削除して本題から始める）

❌ 「近年、〇〇業界を取り巻く環境が大きく変化しています」
✅ （一般論を削除して具体的な課題に入る）
```

### カタカナ語の過剰使用
```
❌ 「ソリューション」→ 「解決策」「仕組み」
❌ 「シームレスな」→ 「つなぎ目のない」「スムーズな」
❌ 「エビデンス」→ 「根拠」「証拠」「データ」
❌ 「コミット」→ 「約束する」「やりきる」
```
※ターゲットがIT業界など専門職の場合は逆に適切なカタカナ語の使用が信頼につながる

### 空虚な美辞麗句
```
❌ 「革新的な」「最先端の」「業界随一の」（根拠なし）
❌ 「使いやすさを追求した」「品質にこだわった」（当然のこと）
❌ 「〇〇の未来を変える」（大げさで信頼されない）
```

## AI生成コピーの修正パターン（日本語版）

AIが生成しやすい問題コピーのパターンとその修正方法：

### パターン1：過剰な列挙
```
❌ 「本製品は、使いやすさ、コスト削減、時間効率化、
    品質向上、チームコミュニケーション改善、セキュリティ強化を
    実現します」

✅ ターゲットに最も刺さる1〜2点に絞り込む
```

### パターン2：感情のない羅列
```
❌ 「機能A、機能B、機能Cが含まれています」
✅ 「機能Aで〇〇が解決し、機能Bで〇〇の時間が半分に、
    機能Cは〇〇な時でも安心です」
```

### パターン3：テンプレート的な締め
```
❌ 「まずはお気軽にお問い合わせください」
✅ 「〇〇でお困りでしたら、今すぐ無料相談を予約してください。
    ほとんどの場合、初回の相談だけで方向性が決まります」
```

### パターン4：読者不在の主語
```
❌ 「当社では、〇〇を大切にしています」
✅ 「〇〇を大切にしているから、
    〇〇年間でお客様のリピート率が〇〇%を維持できています」
```

## 編集スコアリング

以下の5軸でコピーを採点（各10点、計50点）：

| 軸 | 問い |
|----|------|
| 明確さ | すぐ意味が取れるか |
| 説得力 | 証拠と具体性があるか |
| 感情共鳴 | 読者の感情に触れているか |
| 行動喚起 | 次のアクションが明確か |
| 自然さ | 声に出して違和感がないか |

35点以下は再編集。45点以上で納品可能。
