# 日本広告法規制 実務ガイド

## このファイルの使い方

広告コピーの制作・チェック時に参照する。
クライアントファイル（`clients/クライアント名.md`）に記載された業種から、
適用される規制セクションを特定して使う。

**免責：** このファイルは実務判断の補助資料です。
最終的な法的判断は弁護士・薬事専門家に確認すること。
規制は改正されるため、重要案件は最新情報を確認する。

---

## 規制の適用マップ

| 業種 | 主な適用法規 |
|------|------------|
| 医薬品・医療機器 | 薬機法（最も厳格） |
| 化粧品 | 薬機法（効能の範囲制限） |
| 健康食品・サプリメント | 薬機法・景表法・食品表示法 |
| 機能性表示食品・特定保健用食品 | 食品表示法（届出内容の範囲） |
| 通信販売全般 | 特定商取引法 |
| 定期購入・サブスク | 特定商取引法（2022年改正・厳格化） |
| 金融・投資・保険 | 金融商品取引法・保険業法 |
| 不動産 | 宅地建物取引業法・不動産公正競争規約 |
| 求人・人材 | 職業安定法・労働基準法 |
| すべての広告 | 景品表示法 |

---

## 第1章：薬機法（医薬品医療機器等法）

### 規制の基本構造

薬機法は「医薬品的な効能・効果」を持つかのような表示を、
承認を受けていない製品に対して行うことを禁止している。

**対象：** 医薬品・医療機器・化粧品・健康食品・サプリメント・雑貨

---

### 1-1. 化粧品の広告規制

**化粧品でできる表現の範囲（薬機法56条の効能の範囲内）**

化粧品は「人体への作用が緩和なもの」と定義されており、
表現できる効能は厚生労働省が定めた56項目に限定される。

主な認められる表現の例：
- 「肌にうるおいを与える」
- 「肌を清潔にする」
- 「肌を整える」
- 「毛髪につやを与える」
- 「乾燥による小じわを目立たなくする」

**NG表現（医薬品的効能の標榜）**

| NG表現 | 理由 | 代替表現 |
|--------|------|---------|
| 「シミが消える」 | 治療的効能 | 「うるおいを与え、明るい印象の肌へ」 |
| 「ニキビを治す」 | 治療的効能 | 「清潔に保つ」「肌荒れを防ぐ」 |
| 「肌の細胞を再生する」 | 医学的メカニズムの標榜 | 「肌にハリとつやを与える」 |
| 「コラーゲンを増やす」 | 体内作用の標榜 | 「うるおいを与えてハリのある肌に」 |
| 「紫外線ダメージを修復する」 | 治療的表現 | 「紫外線などの外的ストレスからやさしく守る」 |
| 「毛穴を消す」 | 治療的効能 | 「毛穴を目立たなくする」はNG。「肌をなめらかに整える」 |

**グレーゾーン（使用には注意が必要）**

- 「エイジングケア」→ 「年齢に応じたケア」という意味では使用可。ただし「老化を防ぐ」という意味での使用はNG
- 「美白」→ 医薬部外品の効能として認められているが、化粧品での「メラニンの生成を抑える」等の表現は医薬部外品に限られる
- 「ターンオーバー」→ 直接的な促進効果の主張はNG。「肌本来のリズムをサポート」程度なら許容範囲

---

### 1-2. 健康食品・サプリメントの広告規制

**原則：食品に医薬品的効能は表示できない**

健康食品・サプリメントは食品であり、病気の治療・予防効果を
標榜することは薬機法違反になる。

**絶対にNG（行政処分・刑事罰の対象）**

| NG表現 | 違反の根拠 |
|--------|----------|
| 「〇〇が治る」「〇〇に効く」 | 医薬品的効能の標榜 |
| 「血糖値を下げる」 | 医薬品的効能（特保・機能性表示以外） |
| 「がんを予防する」 | 医薬品的効能 |
| 「医師が推薦する治療法」 | 医薬品的効能＋虚偽誇大 |
| 「飲むだけで痩せる」 | 医薬品的効能＋誇大広告 |

**許容される表現の考え方**

```
体の部位・成分の説明 → OK
  「〇〇という成分を配合しています」

栄養素の一般的な機能 → 条件付きOK
  「鉄は赤血球を作るのに必要な栄養素です」
  （栄養機能食品として届出している場合）

生活習慣・体調管理との関連 → 文脈次第
  「日々の健康管理に」「栄養補給に」
```

**機能性表示食品・特定保健用食品（特保）の場合**

届出・許可された範囲内であれば機能性の表示が可能：
- 「本品には〇〇が含まれます。〇〇は〇〇の機能があります」
- 届出表現を一字一句変えないこと
- 注意喚起事項・摂取目安量の併記が必要

**グレーゾーン表現と現在の傾向**

かつて広く使われていた回避表現も規制が強まっている：

| 表現 | 現在の傾向 |
|------|----------|
| 「〇〇をサポートする」 | 前後の文脈で医薬品的効能の暗示と判断されることが増えている |
| 「〇〇に着目した」 | 単独では許容範囲だが、全体のトーンで判断される |
| 「〇〇が気になる方に」 | 病名・症状との直接的な紐付けは避ける |
| 体験談での「〇〇が治った」 | 体験談であっても薬機法・景表法違反になる |

**体験談・口コミの注意点**

- 使用者の体験談でも「病気が治った」「症状が消えた」はNG
- SNSインフルエンサー・アンバサダーの投稿も広告主が管理責任を負う
- ステルスマーケティング規制（2023年10月施行）により
  広告であることの明示が義務化

---

### 1-3. 医薬部外品

医薬部外品は承認を受けた効能・効果の範囲内で表示が可能。

- 「メラニンの生成を抑え、シミ・ソバカスを防ぐ」（美白有効成分配合の場合）
- 「ニキビを防ぐ」（ニキビ予防の承認を受けた場合）

**注意：** 承認を受けた効能表現のみ。それ以上の表現は医薬品的効能の標榜になる。

## 第2章：景品表示法（不当景品類及び不当表示防止法）

### 規制の基本構造

消費者が実際よりも良いものと誤認する表示（優良誤認）と
取引条件が実際より有利と誤認する表示（有利誤認）を禁止。

**違反した場合：** 措置命令・課徴金（売上の3%）

---

### 2-1. 優良誤認表示

**No.1・1位・最高表示のルール**

使用するには以下の条件をすべて満たす必要がある：

1. 調査機関が第三者（自社調査の場合は明記）
2. 調査対象が明確（業界全体か、特定カテゴリか）
3. 調査時期が明確（古すぎる調査は問題になる）
4. 調査方法が合理的
5. 広告に調査概要を明記（小さい打消し表示は無効になるケースがある）

**適切な表示例：**
```
「〇〇部門 顧客満足度No.1」
（〇〇調査機関調べ、2024年10月、対象：〇〇カテゴリ利用者1,000名）
```

**最上級表現のチェックリスト：**
- 「業界最安値」→ 全競合と比較した根拠があるか
- 「業界初」→ 本当に初めてか、調査済みか
- 「最高品質」→ 客観的な品質基準と根拠があるか
- 「唯一の〇〇」→ 本当に唯一か

---

### 2-2. 有利誤認表示

**二重価格表示のルール**

「通常価格〇〇円 → セール価格〇〇円」という表示は、
通常価格が実際に販売されていた価格でなければならない。

- 最近相当期間（2ヶ月以上が目安）販売していた価格
- 同一の販売業者における価格
- セール期間が長すぎると通常価格と見なされなくなる

**NG：**
- 最初から値引き前提で高い定価を設定する
- ほぼ販売していない価格を「定価」として表示する

---

### 2-3. 打消し表示

「\*条件があります」「※一部対象外」などの小さな注記で
大きな強調表示を打ち消そうとする表現は無効になるケースがある。

**2023年10月 消費者庁ガイドライン更新：**
- 打消し表示は強調表示と同等の視認性が必要
- 動画広告での短時間表示も問題になる
- スマートフォン画面での視認性も考慮が必要

**実務上の安全な設計：**
```
❌ 「月額0円！」（大きく表示）
   ※初月のみ。2ヶ月目以降は月額2,980円（小さく表示）

✅ 「初月0円、2ヶ月目から月額2,980円」（条件を同等の視認性で表示）
```

---

### 2-4. 比較広告のルール

比較広告は以下の条件を満たす場合に許容される：

1. 比較内容が客観的に実証されている
2. 実証された事実を正確かつ適正に引用している
3. 競合を中傷・誹謗していない

**注意：** 競合他社名を直接出す比較広告は日本では
文化的にも法的にもリスクが高い。
「他社比〇〇%削減」程度にとどめ、競合名は出さない方が安全。

## 第3章：特定商取引法

### 通信販売の広告記載義務

ECサイト・LP・SNS広告を問わず、通信販売の広告には
以下の記載が義務（記載漏れは行政処分の対象）：

**必須記載事項：**
- 販売価格（送料も明示）
- 支払時期・支払方法
- 商品の引渡し時期
- 返品・交換の条件（返品特約）
- 事業者の名称・住所・電話番号
- 代表者または責任者の氏名

**LPでの実装：**
- フッターまたは特商法表記ページへのリンクを必ず設置
- 広告の「購入ページ」への導線上に特商法表記が必要

---

### 定期購入・サブスクの規制（2022年改正・重要）

2022年6月施行の改正特商法により、定期購入の表示規制が
大幅に強化された。違反は業務停止命令・刑事罰の対象。

**注文確定前に明示が必要な事項：**

1. **定期購入であること**（「定期」という文言を明確に）
2. **全契約期間と総額**（「6回縛り・総額〇〇円」など）
3. **各回の支払金額**
4. **解約条件・方法**（電話のみでの解約受付は問題になりやすい）
5. **解約期限**（次回発送の何日前までか）

**NG事例（行政処分多数）：**
```
❌ 「初回980円！」を大きく表示し、
   定期購入・2回目以降の価格を小さく、または確認しにくい場所に表示
   
❌ 最終確認画面で定期購入の条件が確認できない

❌ 解約方法が電話のみで、電話がつながらない
```

**安全な設計の原則：**
```
✅ 「定期購入プラン：初回980円・2回目以降3,980円（6回継続が条件）」
   を購入ボタンの近くに、購入ボタンと同等以上の視認性で表示

✅ 最終確認画面に定期購入条件の再確認チェックボックスを設置

✅ 解約方法をLPに明示（Webまたはメールでの解約を設ける）
```

---

### ステルスマーケティング規制（2023年10月施行）

**対象：** 広告主が関与するすべての広告表示

インフルエンサー・アンバサダー・アフィリエイターが
広告であることを明示しない投稿は景表法違反になる。

**必要な表示：**
- 「#PR」「#広告」「#プロモーション」「#タイアップ」
- ストーリーズ等でのPaidPartnershipラベル
- ブログでの「本記事はPRを含みます」明記

**注意：**
- 「#提供」「#ギフト」だけでは不十分な場合がある
- 表示位置（最初か最後か）も問題になりうる
- インフルエンサーへの指示・管理も広告主の責任

## 第4章：業種別追加規制

### 4-1. 金融商品・投資・保険

**金融商品取引法の主な規制：**
- 元本保証のない商品での「必ず儲かる」「リスクゼロ」→ 絶対NG
- 過去の運用実績の強調（将来の成果を示唆する表現）→ 要注意
- 「〇〇%の利回り保証」→ 保証できない場合はNG

**必要な表示：**
- 元本割れリスクがある商品はリスクの明示
- 手数料・コストの明示
- 金融商品取引業者の登録番号

---

### 4-2. 不動産広告

**不動産公正競争規約の主な規制：**
- 「徒歩〇分」→ 80m＝1分で計算、端数は切り上げ
- 「駅近」→ 徒歩10分以内が目安（それ以上は「駅から〇分」と明記）
- 「新築」→ 建築後1年未満かつ未居住のもの
- 「格安」「激安」→ 比較対象が明確でなければ使用不可
- 間取り図の面積は壁芯計算か内法計算かを明記

---

### 4-3. 求人・採用広告

**職業安定法の主な規制：**
- 虚偽の求人（実際と異なる労働条件）→ 禁止
- 給与・労働時間の明示義務
- 「高収入」「高給」→ 具体的な金額を示す必要がある
- 「アットホームな職場」→ 規制対象ではないが、
  実態と異なる場合は問題になりうる

## 第5章：実務チェックフロー

### 広告制作前の確認

```
Step 1: クライアントの業種を確認
        ↓
Step 2: 適用される規制セクションを特定（上記の規制適用マップ参照）
        ↓
Step 3: 使用予定の訴求・表現をリストアップ
        ↓
Step 4: 各表現を以下の基準で判定
```

### 表現の判定基準

| 判定 | 基準 | 対応 |
|------|------|------|
| ✅ 使用可 | 根拠あり・規制範囲内 | そのまま使用 |
| ⚠️ 要条件 | 根拠・表示条件を満たせば可 | 条件を確認・追記して使用 |
| ❌ 使用不可 | 規制違反・根拠なし | 代替表現を使用 |
| ❓ グレー | 判断が難しい | 専門家確認を推奨 |

### コピー完成後のチェックリスト

**全業種共通：**
- [ ] 最上級表現（No.1・最高・唯一）に根拠があるか
- [ ] 効果・効能の断定表現がないか
- [ ] 二重価格表示の根拠となる通常価格は実際に販売されていたか
- [ ] 打消し表示が強調表示と同等の視認性で表示されているか
- [ ] ステマ規制対応（インフルエンサー活用の場合）

**通信販売の場合：**
- [ ] 特商法の必須記載事項が揃っているか
- [ ] 定期購入の場合、条件の明示は適切か

**健康・美容商品の場合：**
- [ ] 医薬品的効能・効果の標榜がないか
- [ ] 体験談に「治った」「効いた」などの表現がないか
- [ ] インフルエンサーの投稿に#PRが明示されているか

## 参考：代替表現の引き出し

よく使いたいが規制上NG・グレーな表現と、代わりに使える表現：

| 使いたい表現 | 問題点 | 代替表現 |
|------------|--------|---------|
| 「〇〇が治る」 | 薬機法違反 | 「〇〇の悩みにアプローチする」「〇〇をケアする」 |
| 「痩せる」 | 健康食品では薬機法違反 | 「健康的な体重管理をサポート」（根拠があれば） |
| 「シミが消える」 | 化粧品では薬機法違反 | 「明るい印象の肌へ導く」「うるおいを与え、肌を整える」 |
| 「業界No.1」 | 根拠なし | 「〇〇部門 顧客満足度No.1（〇〇調査・詳細条件明記）」 |
| 「初回無料！」（定期縛り） | 特商法違反リスク | 「初回〇〇円・2回目以降〇〇円（〇回継続）」 |
| 「必ず効果が出ます」 | 景表法・薬機法 | 「〇〇%のお客様が実感（自社調査・n=〇〇〇）」 |
| 「副作用なし」 | 医薬品的主張 | 使用しない（化粧品・食品には「副作用」という概念がない） |
