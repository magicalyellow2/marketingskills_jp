# 日本語コピーライティング

## 制作開始前の確認

**クライアントファイルを先に確認：**
`clients/クライアント名.md`が存在する場合は必ず先に読み込む。

以下を把握してから書き始める：

### 1. ページの目的
- ページ種別（LP・HP・価格ページ・特集ページ・記事など）
- 唯一の主要アクション（購入・申し込み・資料請求・問い合わせのいずれか）
- ファーストビューで何を伝えるか

### 2. ターゲット
- 具体的な読み手（年齢・職業・生活状況）
- 解決したい悩みと現在の状況
- 読む前に持っている疑念・懸念
- 日常で使っている言葉（広告主の言葉ではなく）

### 3. 商品・サービス
- 核心的なベネフィット（機能ではなく、生活がどう変わるか）
- 差別化ポイント（競合にはない何か）
- 証拠・実績（数字・事例・受賞歴など）

### 4. 流入経路
- どこから来るか（検索・SNS広告・メール・紹介など）
- 読む前にどのくらい知っているか

## 日本語コピーライティングの原則

### 原則1：明確さを優先する

上手く見せようとして回り道をしない。伝わらないコピーは存在しないのと同じ。

```
❌ 「革新的なアプローチで、あなたのビジネスの可能性を最大化します」
✅ 「月次レポートの作成時間を、3時間から15分に短縮します」
```

### 原則2：機能ではなくベネフィットを書く

機能は「何ができるか」、ベネフィットは「どう変わるか」。

```
❌ 「AI搭載の自動分類機能を搭載」（機能）
✅ 「毎朝の仕訳作業がゼロになります」（ベネフィット）
```

**変換の方法：**
機能を書いたら「つまり？」「それで読者はどうなる？」と問い直す。

### 原則3：具体的に書く

曖昧な言葉は信頼を下げる。数字・固有名詞・時間軸で具体化する。

```
❌ 「多くのお客様にご利用いただいています」
✅ 「累計導入企業2,400社（2024年3月現在）」

❌ 「効果が出るまで時間がかかります」
✅ 「多くの方が2〜4週間で変化を実感しています」
```

### 原則4：読者の言葉を使う

自社の専門用語やマーケティング用語ではなく、読者が日常会話で使う言葉を使う。

```
❌ 「UI/UXを最適化することで、コンバージョンを向上させます」
✅ 「使いやすいデザインで、問い合わせが増えます」
```

**ヒント：** 口コミ・レビュー・SNSの投稿・問い合わせ内容から「顧客の生の言葉」を収集して使う。

### 原則5：能動態で書く

受動態は責任の所在を曖昧にし、コピーに力がなくなる。

```
❌ 「多くの賞を受賞させていただいております」
✅ 「グッドデザイン賞2023を受賞しました」

❌ 「〇〇が提供されます」
✅ 「〇〇を提供します」
```

### 原則6：日本語の感情的共鳴を活用する

英語圏のコピーは直接的な「利得」訴求が強いが、日本市場では**不安の除去・安心の提供・共感**が特に有効。

```
[不安の除去]
「初めての方でも、スタッフが丁寧にサポートします」
「万が一のときも、全額返金対応です」

[共感の表現]
「〇〇で疲れていませんか。そんな方のために作りました」
「私たちも同じ悩みを抱えていました」

[安心の提供]
「〇〇年間、〇〇社に選ばれ続けています」
「解約はいつでも1クリックで完了します」
```

### 原則7：季節感・文化的文脈を活用する

日本のコピーは季節・行事・年中行事との接続が強い説得力を持つ。

- 年度替わり（3〜4月）：新生活・新しい習慣
- 梅雨〜夏：不快・効率・涼しさ
- 年末年始：振り返り・新年の目標
- ビジネス文脈：決算期（3月・9月）、予算消化

## ページ構造フレームワーク

### ファーストビュー（Above the Fold）

**キャッチコピー（ヘッドライン）**
- 最も重要なメッセージを1行に凝縮
- ターゲットの悩みか、得られる変化のどちらかを中心に据える
- 「誰のための何か」が一瞬で伝わること

**キャッチコピーの型（日本語）：**
```
[悩み直球型]
「〇〇に悩む方へ」
「〇〇がうまくいかない理由があります」

[変化・結果型]
「〇〇が、〇週間で変わります」
「〇〇なしで、〇〇を実現する方法」

[ターゲット指定型]
「〇〇の方のための〇〇」
「はじめて〇〇する方に」

[問いかけ型]
「まだ〇〇で消耗していますか？」
「〇〇、うまくいっていますか？」
```

**サブコピー（サブヘッドライン）**
- ヘッドラインを受けて、具体的に展開する
- 1〜2文、最大60文字程度
- 「誰が・何を・どうやって・どうなるか」のいずれかを補完する

**メインCTA**
- ボタンテキストは「アクション＋得られるもの」の構造
- 「送信する」「登録する」より具体的に

```
❌ 「送信する」「申し込む」
✅ 「無料で資料を受け取る」「まず30日間試してみる」「今すぐ相談する（無料）」
```

### ページ構成の流れ

| セクション | 目的 | 日本市場での注意点 |
|-----------|------|------------------|
| 社会的証明 | 信頼構築 | 数字＋具体的な企業名・個人名の実名表記が信頼度を上げる |
| 課題・共感 | 読者に「わかってもらえた」と感じさせる | 悩みを言語化する共感が、欧米より重視される |
| 解決策・ベネフィット | 変化の提示 | 3〜5つに絞る。多すぎると散漫になる |
| 仕組み・使い方 | 複雑さの軽減 | ステップ数を少なく見せる（「3ステップで完了」など） |
| 信頼・実績 | 懸念の払拭 | 受賞歴・メディア掲載・士業監修なども有効 |
| よくある質問 | 購入前の不安除去 | 日本は「聞くのが恥ずかしい」文化なのでFAQが特に重要 |
| 最終CTA | 行動促進 | リスク除去（返金保証・解約自由）を再度明示する |

## ヘッドラインの作り方

### 強いヘッドラインの特徴
- 誰に向けたものか明確
- 得られる変化が具体的
- 読んだ瞬間に続きを読みたくなる
- 「自分のことだ」と思わせる

### 弱いヘッドラインのパターン（避ける）
```
❌ 「〇〇ならお任せください」（主語が自社）
❌ 「高品質・低コスト・スピード対応」（当たり前の羅列）
❌ 「〇〇の新常識」（何が新常識か分からない）
❌ 「あなたの〇〇をサポートします」（漠然としすぎ）
```

### 練り直しの方法
ヘッドラインを書いたら、以下を確認する：
1. 競合他社が同じことを言えるか？ → 言えるなら差別化が足りない
2. 「誰が・何を」が抜けていないか？
3. 声に出して読んで自然か？

## CTAコピーのガイドライン

### 弱いCTA（避ける）
- 「詳しくはこちら」「クリック」「送信」「確認する」

### 強いCTA（使う）
- 「〇〇を無料で試す」
- 「今すぐ相談する（費用なし）」
- 「資料を無料で受け取る」
- 「まずは〇〇から始める」
- 「30秒で完了する登録はこちら」

**公式：** [動詞] ＋ [得られるもの] ＋ [不安除去の一言（任意）]

## ページ種別ごとのガイダンス

### LP（ランディングページ）
- 1ページ1メッセージ・1CTA
- 流入広告のヘッドラインとの一致性が最重要（メッセージマッチ）
- ナビゲーションメニューは原則非表示にする
- すべての証拠・FAQをページ内に収める

### ホームページ
- 複数のターゲット・複数の意図を持つ訪問者を受け止める
- 最も重要な転換への動線を最短にする
- 各セグメントへの「入口」を明確にする

### 価格ページ
- 「どのプランが自分に合うか」という不安を解消する
- 推奨プランを視覚的に明示する（「おすすめ」バッジなど）
- 比較表は「得」ではなく「損しない選択」として提示する
- 年払いと月払いの差額を分かりやすく示す

### 機能・サービスページ
- 機能から入らず、その機能で解決される悩みから入る
- 具体的なユースケース・before/afterを示す
- 次のアクション（試す・問い合わせる）への動線を忘れない

## トーン・文体の設定

コピーを書く前にトーンを決める：

| 軸 | 選択肢 |
|----|--------|
| 丁寧さ | ですます調 ／ だ・である調 ／ 混在（ですます基調）|
| 距離感 | 親しみやすい ／ プロフェッショナル ／ 権威的 |
| 感情温度 | 共感・感情的 ／ 論理・データ的 ／ ミックス |
| 個性 | 真剣・誠実 ／ 軽快・ユーモア ／ 専門的・硬め |

**ターゲット別の傾向：**
- 20〜30代消費者：口語に近い、共感重視、カジュアルOK
- 40〜60代消費者：丁寧語、信頼重視、慎重な言い回し
- BtoB担当者：論理・数字重視、責任転嫁リスクへの配慮
- 経営者：端的・成果重視、時間がない前提

## アウトプット形式

コピーを納品するとき：

### ページコピー
セクションごとに整理して提出：
- キャッチコピー・サブコピー・CTA
- 各セクションの見出しと本文
- サブCTA

### 注釈
主要な選択について：
- なぜこの構造にしたか
- どの原則を適用したか

### バリエーション
キャッチコピーとCTAは最低3案を提示：
- A案：[コピー] — [意図の説明]
- B案：[コピー] — [意図の説明]
- C案：[コピー] — [意図の説明]
