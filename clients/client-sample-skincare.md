## 5. 顧客の言葉

### 問題・悩みの表現（実際のレビュー・問い合わせから）

```
「産後から急に肌が荒れるようになって…」
「何を使っても赤くなってしまう」
「成分表を全部読んでも不安が消えない」
「保湿力が高いものは大体合わない」
「解約が面倒で続けたくないのに続けている」
「どれが本当に無添加なのか分からない」
```

### 自社への評価（実際のレビューから）

```
「本当に肌に何も起きなかった」
「やっとこれだ、と思えた」
「成分がシンプルで安心できる」
「保湿力の割にベタつかない」
「解約がWebで簡単にできた（安心して続けられる）」
```

### 使うべき言葉

- 「敏感肌」「肌荒れ」「乾燥」（顧客が検索・会話で使う言葉）
- 「合わない」「刺激になる」（顧客の実感の表現）
- 「やっと見つかった」「これだ」（共感・解決感）
- 「成分」「無添加」「シンプル」（信頼の根拠として有効）

### 使わない言葉

- 「スキンケアソリューション」（顧客は使わない）
- 「イノベーティブな処方」（信頼されない）
- 「革新的な」（根拠がなく空虚）
- 「肌を再生する」「細胞を活性化」（薬機法NG）
- 「効く」「治る」「改善する」（薬機法NG）

## 6. ブランドの声

**トーン：** 親しみやすく・誠実・専門的すぎない

**文体：** ですます調基調（SNSではやや口語的もOK）

**温度感：** 共感重視（悩みを言語化してから解決策へ）

**個性を表す言葉：** 誠実・やさしい・シンプル・信頼・安心

### 禁止事項

**使ってはいけない表現：**
- 「治る」「改善」「再生」「効く」などの薬機法NG表現
- 効果の断定（「必ず〇〇になります」）
- 根拠のない最上級（「日本一の保湿力」など）
- 競合他社の直接的な批判・名指し

**避けるべきトーン：**
- 押しつけがましい・煽り系（「今すぐ！」の多用）
- 過剰な感嘆符・大げさな表現
- 医療機関のような権威的すぎる表現

**競合他社への言及：**
- 社名・製品名の直接言及：禁止
- 比較表現（他社比〇〇%）：禁止（根拠の確保が難しいため）

**承認済みの表現（法務確認済み）：**
- 「うるおいを与える」「肌を整える」「乾燥を防ぐ」
- 「無添加処方」（全成分で対象5成分が含まれない場合の表現）

**過去にNGになった表現：**
- 「肌のターンオーバーを促進する」→ 医薬品的効能として指摘
- 「毛穴を引き締める」→ 薬機法の範囲外として指摘
- 「〇〇%がシミ改善を実感」→ 「シミ改善」が薬機法NG

**社内承認フロー：**
担当確認（1日）→ 法務確認（2営業日）→ 代表確認（1日）
合計目安：4〜5営業日
